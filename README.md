# DB_editor

Лёгкий визуальный редактор схем баз данных. Один HTML файл — без установки, без зависимостей.

![DB Editor Preview](screenshot.png)


[![Download](https://img.shields.io/badge/Download-DB_Editor-e94560?style=for-the-badge)](https://github.com/NaitSide/DB_editor/releases/download/DB_Editor_v1.0/DB_editor.html)

## ✨ Возможности

- **Drag & drop** — перемещай таблицы
- **Ортогональные стрелки** — связи между полями с прямыми углами (как в IDEF0)
- **Перестановка строк** — перетаскивай поля между таблицами
- **Редактирование** — добавляй/удаляй таблицы и поля прямо в интерфейсе
- **Сохранение в JSON** — перенос схемы между компьютерами
- **Экспорт SQLite** — генерирует рабочий `.sqlite` файл с `CREATE TABLE`
- **Скриншот** — экспорт схемы в PNG
- **Кликабельный заголовок** — можно переименовать схему

## 🚀 Использование

1. Скачай `db_schema_final_editor.html`
2. Открой в браузере
3. Готово — никакой установки не нужно

## 🎮 Управление

| Режим | Описание |
|-------|----------|
| ✋ Двигать | Перетаскивай таблицы |
| → Стрелка | Кликни на точку поля → кликни на другую точку |
| ↕ Строки | Перетаскивай поля между таблицами |

**ПКМ на стрелке** — удалить связь  
**ESC** — отмена действия

## 💾 Форматы экспорта

- **JSON** — полная схема с позициями таблиц и стрелками
- **SQLite** — готовый файл базы данных
- **PNG** — скриншот схемы без интерфейса

## 🛠 Технологии

Vanilla JS · HTML · CSS · [sql.js](https://github.com/sql-js/sql.js) · [html2canvas](https://html2canvas.hertzen.com)
